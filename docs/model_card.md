# Temporal model card

The Phase 4 model is a lightweight optional GRU. It predicts local ENU motion increments and yaw correction, not global coordinates. It emits log variance values for an uncertainty-aware downstream fusion layer.

Training requires a compatible CPU PyTorch installation. The current execution environment could not install PyTorch because the wheel download exhausted the temporary filesystem; therefore neural training and ablation metrics are explicitly marked not run. Classical synthetic baselines remain executable and tested.

The physics option adds yaw/dynamics residual and non-holonomic lateral-motion penalties. It must be compared against the same seed, sequence split, and window configuration as the no-physics variant.

## Mobile deployment status

The Android app contains a real `LocalOnnxInferenceRepository` boundary using ONNX Runtime Android. The bundled model asset is intentionally absent because no validated trained model is available. Missing or malformed model assets return an explicit mock fallback status; the UI must not label this as neural inference. Metadata is generated by `python scripts/generate_model_contract.py` from `src/aethernav/models/contract.py`, written to `app/src/main/assets/aethernav_model_metadata.json`, and loaded by Android `ModelMetadata`. `python scripts/validate_model_contract.py` validates the contract.
